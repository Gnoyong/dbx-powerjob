# 安全

## 凭据和连接

连接密码只用于 sidecar 登录，不应进入 UI 日志、toast、测试快照或保存操作日志。开发环境的 `.dbx-dev/` 含明文凭据，调试结束后删除。生产环境使用 HTTPS；跳过 TLS 校验只用于可信的自签名环境。

## 权限

连接的只读设置只影响 UI 能力门控，真正的写权限由 PowerJob 账号权限决定。sidecar 对 ID、分页、可编辑任务字段、工作流引用和配置对象执行服务端校验，不能仅依赖前端校验。

## 数据暴露

查询响应通过字段投影返回，避免把不需要的 PowerJob 字段传给 UI。日志和实例详情可能含业务数据，导出文件名只使用实例 ID，不在文件名中写任务参数或凭据。

## 写入安全

未知写入结果不得自动重发。工作流保存通过 fingerprint、节点 ID 和回读确认降低并发覆盖风险，但它不能替代 PowerJob 服务端事务或锁。发现疑似重复写入时，先核对 PowerJob 实际状态。
